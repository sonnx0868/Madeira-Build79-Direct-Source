# Corresponding source

The exact UI source and release builder are included with this release. The
source archive also contains the Madeira source snapshot matching the original
binary lineage, its pinned FEX/Wine/DXMT sources, and the runtime patch and test
material used by the BeamNG 0.34 compatibility build.

Original project: <https://github.com/willfaust/Madeira>

Preserved fork snapshot: `44b4b67e116b5bc813f7a35c9ed3b7d8ad3b5416`, whose tracked source tree matches
upstream Madeira `97e2ce26e6dc9e4a38976f3b5deb9272d64558eb` except for its GitHub Actions
workflow. See the source manifest for exact hashes and provenance.

The source and IPA must remain available together under GPLv3 when this build
is redistributed.
